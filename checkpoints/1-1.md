# Checkpoint 1-1 · Point an agent at your content

_Correct if you're still on the Green & Gather seed._

**The route.** `app/app/api/agent/route.ts` no longer streams the fixed reply. It creates an MCP
client against `SANITY_CONTEXT_MCP_URL` with `Authorization: Bearer <your organization token>`,
hands the endpoint's tools to `streamText`, and returns a UI message stream. `ChatPanel.tsx` is
unchanged.

**The trace.** For _"What vegan bowls are under $12 in Austin?"_ you should see one `groq_query`
call (possibly preceded by `initial_context` or `schema_explorer` if the route didn't fetch
initial context into the system prompt). Its input is GROQ you can read. Expect the shape:

- a `_type == "menuItem"` predicate
- `"vegan" in dietaryFlags`
- `category == "bowl"`
- `priceCents < 1200` (cents, not dollars — if you see `< 12`, the agent guessed the unit; the
  schema description says integer cents)
- a location predicate that dereferences to market: `"austin" in locations[]->market`, or a
  `references()` against Austin location ids

**The answer.** Exactly one item: **Harissa Chickpea Bowl**, $11.50.

**If you got two items** (Harissa plus Charred Broccoli & Farro), the location predicate did no
work — Charred Broccoli is deliberately absent from both Austin locations. **If you got four**,
the price predicate is missing. **If you got zero**, look for `status`, `priceCents` units, or a
market value spelled wrong.

**If nothing comes back at all** and the trace shows no tools, check the token before the code:
`403 contextGrantRequired` means a project token or Context not enabled; `-32004` means the
schema isn't deployed.
