# Checkpoint 1-5 · Personalize it

_Correct if you're still on the Green & Gather seed._

**The route.** Reads `guestId` from the body, calls `getGuest()` from `app/lib/loyalty.ts`, and
appends a guest block to the system prompt only when a guest resolves. A comment notes that
identity comes from the verified session in a real app. **No** `groqFilter` changes, **no**
writes to Sanity, **no** schema changes, `ChatPanel.tsx` unchanged.

**"What do you recommend?" as `dara`.** The trace shows menu queries _and_ an allergen check —
a `knowledge_base_read` if Mission 1-3 is done, otherwise a `groq_query` into the recipe's
allergen tags and the cross-contact statement. The answer recommends real items (vegetarian,
since that's on file), avoids or flags peanut exposure unprompted — in particular it should not
recommend her usual Thai Crunch Bowl without mentioning the Sunfield cross-contact concern if the
KB is connected — and may reference Austin.

**"What do you recommend?" anonymous.** Menu queries only. A friendly recommendation with no
allergen check and no mention of peanuts.

**If both answers look the same**, the guest block isn't reaching the prompt. **If the anonymous
answer also checks allergens**, the check instruction is in the base prompt instead of the guest
block. **If the agent tried to add a `groqFilter` per guest**, that's the trap — the profile
changes what gets checked, not what's visible.
