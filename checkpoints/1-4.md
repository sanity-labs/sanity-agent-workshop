# Checkpoint 1-4 · Teach it which source to use

_Correct if you're still on the Green & Gather seed._

**Before.** The three-times test on _"Anything with no sesame?"_ and _"Is it safe for my sesame
allergy?"_ probably showed inconsistency — both to GROQ some of the time, or both to the KB. If
they were already consistent three times running, the agent may have skipped the changes; that's
fine and the mission is done.

**After.** Two changes and nothing else:

1. **A routing table in the system prompt** that says, in some words: computed-over-a-set menu
   facts → the menu dataset tools; safety, guarantees, cross-contact, substitutions, policy → the
   knowledge base; never answer safety from menu fields.
2. **Re-described tools.** `groq_query` renamed to something like `query_menu` with a description
   that names the domain _and_ the boundary ("NOT for allergen safety…"); `knowledge_base_read`
   renamed to something like `read_food_safety_kb` with its own boundary ("NOT for counts, prices,
   listings").

**The test.** Three fresh conversations each:

| Question                            | Every time                                                                                                                                                            |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "Anything with no sesame?"          | the menu/GROQ tool — a filter on `allergens`, answer lists items (Citrus Fennel Salad, House Pickles, Cheese Quesadilla among the low-cal ones; more across the menu) |
| "Is it safe for my sesame allergy?" | the KB tool — an answer about shared surfaces and what the brand will guarantee, ending with the cross-contact statement                                              |

**If "is it safe" still goes to GROQ**, the GROQ tool's description lacks an explicit boundary.
**If "anything with no sesame" goes to the KB**, the routing table needs to say that filtering on
declared allergens is a menu fact.
