# @starter/sanity-types

`sanity.types.ts` is generated here by `pnpm typegen` (Sanity TypeGen, configured in
`studio/sanity.cli.ts`). It is gitignored.

The app shell deliberately does **not** import from this package, so `pnpm dev` works before
typegen has ever run. It exists for the code you and your agent write during the workshop:
run `pnpm typegen` and import `@starter/sanity-types` wherever you want typed GROQ results.
